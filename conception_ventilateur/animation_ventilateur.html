Hypothèses du modèle
  • Une seule section de pale, au rayon moyen quadratique r_m (méthode de l'élément de pale réduite) : u = ω r_m, c_a = Q / A.
  • Travail d'Euler : Δp_th = ρ u c_u, avec c_u = μ (u − c_a / tan β). μ = 1 − 0,15 / σ (σ = solidité N·corde / 2πr_m) représente la déviation de l'air derrière un nombre fini de pales.
  • Pertes de profil : rendement de l'élément de pale (1 − ε tan φ) / (1 + ε / tan φ), ε = traînée / portance = a + b √(10⁵ / Re). Plaque : a = 0,020, b = 0,035 ; profil bas Reynolds : 0,012 et 0,022. Dents de bord d'attaque ε × 1,08, tubercules × 1,04, bord de fuite dentelé × 1,04.
  • Décrochage : critère de De Haller w₂/w₁ < 0,62 (tubercules 0,55, dents 0,59, hypothèse tirée du retard de décrochage publié). En dessous, le rendement de profil chute.
  • Bout de pale sans anneau : perte 2,85 × jeu / hauteur de pale (essais sur un ventilateur de 806 mm). Avec anneau : 1 % de pertes de paroi, et une fuite qui recircule entre anneau et carter, Q_fuite = C_d π D s √(2 × 0,8 Δp_t / ρ), C_d = 0,6 (0,25 avec labyrinthe), plus le frottement de l'air sur l'anneau.
  • Sortie : ½ρc_a² perdu (moitié récupérée par le diffuseur) et ½ρc_u² perdu (70 % récupérés par le stator).
  • Moteur : P_élec = P_arbre / η_max + P₀. FOC 0,88 et 0,6 W ; EC standard 0,78 et 1,2 W ; PSC 0,50 et 1,0 W. Roulements 0,3 W.
  • Batterie : Δp = Δp_nominal × givre × (Q / Q_nominal)^1,8. Point retenu : le plus grand débit où les deux courbes se croisent.
  • Bruit : indice relatif seulement, 50 log(u_bout) + 20 log(D), moins 3,5 dB (dents), 2,5 dB (bord de fuite dentelé), 1,5 dB (tubercules), jusqu'à 2 dB (faucille) ; plus le bruit de jeu, plus 6 dB en décrochage.
  • Non modélisé : variation radiale (vrillage), écoulement 3D, entrée non uniforme derrière la batterie, effets de l'air froid (ρ = 1,2 kg/m³ partout). C'est un outil pour comparer des variantes, pas pour dessiner la pale : la CFD 3D prendra le relais.
